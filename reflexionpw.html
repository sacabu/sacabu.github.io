Reflexion Personal Paginas Web

Durante este semestre de páginas web, aprendimos el uso de código HTML y CSS a mayor profundidad, desde dar código y diseño hasta maquetar una página web desde cero. Fue una experiencia que me permitió comprender mejor cómo funcionan las páginas que utilizamos diariamente y todo el trabajo que existe detrás de cada sitio web. Antes de cursar esta materia, desconocía gran parte de los procesos necesarios para construir una página funcional y visualmente agradable, por lo que cada tema representó un nuevo aprendizaje. Una de mis trabas en este semestre, sin duda, fue la maquetación. El hecho de tener que sumar todo para que cada elemento encajara correctamente y no quedara mal fue una de las cosas que más se me complicó. En muchas ocasiones parecía que pequeños cambios afectaban por completo la estructura de la página, obligándome a revisar cuidadosamente cada línea de código para encontrar el problema. Sin embargo, conforme fui practicando, comencé a entender mejor la lógica detrás de la distribución de elementos y la importancia de mantener una organización adecuada dentro del proyecto. Sin lugar a dudas, esta materia se caracterizaba por la atención constante a cada cosa que escribías en el código. Desde un “.” hasta un “;”, eran vitales para evitar todo un destrozo en el código. Esto me enseñó que la programación requiere paciencia, concentración y una gran capacidad para identificar errores. Muchas veces los problemas más difíciles de resolver eran ocasionados por detalles mínimos que pasaban desapercibidos a simple vista, pero que impedían el correcto funcionamiento de la página. Otro aspecto importante fue aprender a combinar HTML y CSS para crear diseños más atractivos y profesionales. Gracias a estas herramientas fue posible personalizar colores, tipografías, tamaños, posiciones y diferentes elementos visuales que mejoraban la apariencia de los proyectos. Además, pude comprender que una página web no solo debe verse bien, sino también ser funcional, organizada y fácil de utilizar para cualquier usuario. En conclusión, considero que esta materia me permitió desarrollar habilidades valiosas relacionadas con el diseño y la programación web. Aunque la maquetación y la corrección de errores representaron desafíos importantes, también fueron los aspectos que más me ayudaron a mejorar. Gracias a la práctica constante, logré comprender mejor el funcionamiento de HTML y CSS, así como la importancia de la precisión y la organización al momento de desarrollar una página web. Fue una experiencia que me dejó nuevos conocimientos y una mejor comprensión del trabajo que implica crear sitios web desde cero.
